Connection & what gets sent

The local server uses ACS_API_KEY and TYPESAFE_API_KEY from its environment or workspace .env. Scaffold and draft are sent to ACS and TypeSafe for processing. This page does not store text or credentials. Changing the endpoint to a different origin requires that server to allow browser access.
